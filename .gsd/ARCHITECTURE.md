## Overview

College Carpool is a **FastAPI-based carpooling platform** built for Christ University students. It uses **passwordless OTP authentication** (phone + college email verification), **PostgreSQL with PostGIS** for geospatial ride matching, and **async SQLAlchemy 2.0** for database operations. The database is hosted on **Supabase**.

## Data Flow

### Registration
1. Client → `POST /auth/phone/send-otp` → OTPService creates session, SMSService sends OTP
2. Client → `POST /auth/phone/verify-otp` → Returns `phone_verified_token`
3. Client → `POST /auth/email/send-otp` → Validates college email domain, sends OTP
4. Client → `POST /auth/email/verify-otp` → Returns `email_verified_token`
5. Client → `POST /auth/register` → Validates both tokens, creates User, returns access token

### Ride Lifecycle
1. Driver creates ride → `POST /rides/` (location as PostGIS POINT)
2. Passengers search → `GET /rides/?ride_date=...`
3. *(Not yet implemented)* Passenger requests → ride_requests table
4. *(Not yet implemented)* Driver accepts → ride_participants table
5. *(Not yet implemented)* Ride completes → ride_history table
